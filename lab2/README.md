# Конечные автоматы и их минимизация

## Алгоритм

### Конечный автомат

КА — пятёрка `M(Q, V, δ, q0, F)`:

- `Q` — конечное множество состояний;
- `V` — алфавит;
- `δ` — функция переходов;
- `q0 ∈ Q` — начальное состояние;
- `F ⊆ Q`, `F ≠ ∅` — конечные состояния.

**НКА**: `δ(q, a) = {R, R ⊆ Q}` — переходов по символу может быть несколько
или ни одного.
**ДКА**: `δ(q, a)` содержит не более одного состояния.
**Полностью определённый** автомат: `δ(q, a) ≠ ∅` для всех `q` и `a`.

### Перевод НКА в ДКА (метод подмножеств)

1. Состояния нового ДКА — всевозможные сочетания состояний исходного НКА.
2. Переход из состояния `qᵢqⱼ` — объединение прежних переходов из `qᵢ` и `qⱼ`.
3. Начальное состояние остаётся тем же; конечные — сочетания, содержащие `qf`.
4. Недостижимые состояния удаляются.

В наихудшем случае получается `2ⁿ − 1` состояний.

### Минимизация ДКА

Строятся классы эквивалентности `R(n)`:

1. `R(0) = {F, Q \ F}`.
2. `R(n)` строится по `R(n−1)`: состояния попадают в один класс, если по
   одинаковым символам переходят в `(n−1)`-эквивалентные состояния.
3. Если `R(n) = R(n−1)` — конец, иначе переход к шагу 2.

Алгоритм минимизации:

1. исключить недостижимые состояния;
2. построить классы эквивалентности;
3. каждый класс — состояние нового автомата;
4. функция переходов строится по исходной.

Если автомат не полностью определён, перед минимизацией добавляется
состояние «ошибка», все неопределённые переходы замыкаются на него.

### automaton.py

- `Automaton` — базовый класс, хранит `states`, `alphabet`, `start`,
  `accepting` и проверяет корректность (`q0 ∈ Q`, `F ⊆ Q`, `F ≠ ∅`).
- `NFA(Automaton)` — переходы `{состояние: {символ: {состояния}}}`:
  - `move(states, symbol)` — объединение переходов по символу;
  - `accepts(word)` — допуск слова обходом всех путей.
- `DFA(Automaton)` — переходы `{состояние: {символ: состояние}}`:
  - `delta(state, symbol)` — целевое состояние или `None`;
  - `accepts(word)` — допуск слова одним путём.
- `nfa_to_dfa(nfa)` — метод подмножеств, возвращает `(dfa, subsets)`, где
  `subsets[i]` — множество состояний НКА для состояния `i`.
- `minimize_dfa(dfa)` — классы эквивалентности, возвращает
  `(минимальный_дка, blocks)`, где `blocks[i]` — состояния исходного ДКА,
  объединённые в состояние `i`.
- `_reachable(dfa)` — множество состояний, достижимых из начального.
- `parse_automaton(text)` — разбор текстового описания, тип (`NFA`/`DFA`)
  определяется автоматически.
- `format_automaton(automaton, composition=None)` — вывод автомата;
  `composition` задаёт расшифровку состояний в виде множеств.

### main.py

- читает описание автомата из файла или stdin;
- выводит исходный автомат, результат перевода и минимальный ДКА;
- для переведённого и минимального автоматов печатает состав состояний.

### Формат входных данных

```
states q0 q1 q2
alphabet 0 1
start q0
accepting q2
transitions
q0 0 q0 q1
q1 1 q2
```

Строка перехода: `состояние символ состояние…`. Несколько состояний справа
делают автомат недетерминированным.
