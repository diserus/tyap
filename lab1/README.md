# Лабораторная работа №1. Синтаксический анализатор арифметических выражений

## 1. Цель работы

Разработать программу-парсер, проверяющую соответствие входной строки
заданной контекстно-свободной грамматике (КС-грамматике).

## 2. Теоретическая часть

**КС-грамматика** задаётся четвёркой `G = (T, N, P, S)`, где:

- `T` — множество **терминалов** (элементы, из которых состоят строки языка);
- `N` — множество **нетерминалов** (вспомогательные символы);
- `P` — множество **правил вывода** вида `A -> α`, где `A ∈ N`, `α ∈ (T ∪ N)*`;
- `S` — **аксиома** (начальный нетерминал).

Для нашего языка:

- Терминалы: `+`, `-`, `*`, `/`, `(`, `)`, `number`, `id`
- Нетерминалы: `S`, `E`, `E'`, `T`, `T'`, `F`
- Аксиома: `S`

### Грамматика языка

Чтобы парсер рекурсивного спуска не зацикливался, левая рекурсия устранена:

```
S  -> E
E  -> T E'
E' -> + T E' | - T E' | ε
T  -> F T'
T' -> * F T' | / F T' | ε
F  -> number | id | ( S )
```

Смысл нетерминалов:

| Нетерминал | Назначение                                  |
|------------|---------------------------------------------|
| `S`        | аксиома, выражение в скобках                |
| `E`        | выражение (суммы и разности)                |
| `E'`       | «хвост» выражения: `+ T E'`, `- T E'` или ε |
| `T`        | терм (произведения и деления)               |
| `T'`       | «хвост» терма: `* F T'`, `/ F T'` или ε     |
| `F`        | множитель: число, идентификатор или скобки  |

`ε` означает пустую строку.

## 3. Структура программы

Код разбит на модули:

```
lab1/
├── main.py     — точка входа, чтение выражения, вывод результата
├── errors.py   — класс ParseError (ошибка с позицией)
├── lexer.py    — Token, Lexer, регулярное выражение TOKEN_RE
├── parser.py   — Parser (рекурсивный спуск) и функция parse()
├── tests.py    — автотесты
└── README.md
```

Схема потока данных:

```
lexer  ->  список токенов  ->  parser (рекурсивный спуск)  ->  вердикт
```

### Лексический анализ (`lexer.py`)

Разбивает входную строку на токены с помощью одного мастер-регулярного
выражения `TOKEN_RE`. Токен — это пара **(тип, значение)** и позиция в строке.

- `NUMBER` — `\d+(?:\.\d+)?` (целые и дробные числа);
- `ID` — `[A-Za-z_][A-Za-z0-9_]*`;
- символы `+ - * / ( )`;
- `EOF` — специальный токен конца строки;
- неизвестный символ — ошибка «Недопустимый символ».

Метод `getNextToken()` возвращает очередной токен, `peek()` — подсматривает
текущий, не сдвигая указатель.

### Синтаксический анализ (`parser.py`)

Каждому нетерминалу соответствует метод:

| Нетерминал | Метод           |
|------------|-----------------|
| `S`        | `parseS()`      |
| `E`        | `parseE()`      |
| `E'`       | `parseEPrime()` |
| `T`        | `parseT()`      |
| `T'`       | `parseTPrime()` |
| `F`        | `parseF()`      |

Вспомогательные методы:

- `match(expected)` — сравнивает текущий токен с ожидаемым символом; при
  совпадении «съедает» его, иначе генерирует ошибку
  `Ошибка! Ожидалось: '<expected>'`;
- `match_type(type)` — то же для токенов-классов (`number`, `id`);
- `error(message)` — возбуждает `ParseError` с позицией ошибки.

Метод `parseF()`:

- если токен `(` — вызвать `match('(')`, затем `parseS()`, затем `match(')')`;
- иначе если токен `number` или `id` — просто «съесть» его;
- иначе — ошибка `Ожидалось: number, id или '('`.

Точка входа — `parse()`: вызывается `parseS()`, после чего проверяется, что
достигнут `EOF` (иначе — ошибка «Ожидалось: конец выражения»).

## 4. Запуск

```bash
cd lab1

# интерактивный режим
python3 main.py

# разобрать одно выражение
python3 main.py "2 + 3 * 4"

# автотесты
python3 -m unittest tests -v
```

## 5. Примеры работы

```
>>> 2 + 3 * 4
Выражение корректно.

>>> a * (b - 10)
Выражение корректно.

>>> 5 + + 3
Ошибка! Ожидалось: number, id или '('
5 + + 3
    ^

>>> (7 * 2
Ошибка! Ожидалось: ')'
(7 * 2
      ^
```

## 6. Оценка сложности

- Лексический анализ — `O(n)` по длине строки (один проход регуляркой).
- Синтаксический анализ — `O(n)`: каждый токен просматривается и «съедается»
  не более одного раза, рекурсия вложена по глубине выражения.
- Память — `O(n)` на токены.
